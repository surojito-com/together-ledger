Account journey acceptance matrix

The app has a home of its own. These checks walk the whole account lifecycle from that home with synthetic accounts, and record what each step proved. They are deliberately operational: no personal journey content is read, and no token, password, or private infrastructure identifier appears here.

What is still open

The three link checks are open against the live deployment, not failed. The deployment reported each message as accepted for delivery, but no message reached the synthetic address legal+…@together-ledger.com in the hour after it was sent, so the delivered link could not be read and checked. Whether the address bounced or was never routed is a question for the delivery provider's own log, which also stores the message that was sent.

To close them, run the harness with a delivery-provider read key exported in your own shell. The key is read from the environment, never printed, never written to the evidence record, and never committed:

RESEND_API_KEY=… node scripts/verify-account-journey.mjs --json=evidence.json

The harness then reads the messages it caused, checks each link's origin, completes verification, invitation, and recovery, and reports the delivery state of each message. A mailbox that can be read another way can supply the same links through --links=PATH instead.

Repeating this

Registration is rate limited on purpose, so a repeated run meets the same wall a stranger would; the harness waits the window out rather than reporting a healthy deployment as broken. The browser check needs an existing synthetic account:

QA_BASE_URL=https://app.together-ledger.com QA_ACCOUNT_USERNAME=… QA_ACCOUNT_PASSWORD=… npx playwright test browser-account-journey

Release boundary: this matrix records the account lifecycle at the app's own home. It does not reopen the hosting cutover completed in issue 52, enable billing, migrate browser-local data between hostnames, publish any credential or private deployment identifier, or claim wider launch readiness. Synthetic accounts created by these runs remain in place for inspection and are not real people.
