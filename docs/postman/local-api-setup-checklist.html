Together Ledger · Postman setup

Eight small steps. Then you’re ready.

Check each box as you go. Your progress stays saved in this browser.

  1. You do not need to create a Docker account. If you want one, choose Personal; it is free and you do not need to upgrade for this test.

    1. Open the Docker Desktop download page.
    2. Choose Mac – Apple Silicon for an M-series Mac. Choose Mac – Intel only for an older Intel Mac.
    3. Open the downloaded .dmg file and drag Docker into Applications.
    4. Open Docker Desktop, use its recommended settings, and enter your Mac login password if asked.
    5. Skip sign-in, or sign into the optional Personal account.
    6. If Docker shows Resource Saver mode, click the Play button beside it.
    7. Wait until Docker Desktop says Engine running, then check this box.

  2. On your Mac, press Command + Space, type Terminal, and open it.

  3. Press Return after pasting. The first startup can take a few minutes.

    cd /Users/neo/together-ledger
cp -n .env.example .env
docker compose up --build

  4. Open the readiness check: http://127.0.0.1:4174/readyz. Continue when it shows {"status":"ready"}.

    Email links will appear in Mailpit: http://127.0.0.1:8025.

  5. The username may contain lowercase letters, numbers, and single hyphens—no @ or periods.

    {
  "email": "test101@surojito.com",
  "username": "test101-surojito",
  "password": "a unique test passphrase here"
}

    A successful registration shows 201 Created and "verificationSent": true.

    1. Open Mailpit: http://127.0.0.1:8025.
    2. Open the newest message titled Verify your Together Ledger email.
    3. If you want to test verification in Postman, do not click the email button—the link works only once.
    4. Copy the part of the link after ?verify=.
    5. Open TC-API-003 — Verify the email address in Postman and put that value in the token field.
    6. Press Send. Success shows 200 OK, passing tests, and "emailVerified": true.

  7. Open Together Ledger locally: http://127.0.0.1:4174/.

    Use the complete username or complete email address from registration, plus the exact same password. This local test account will not work on the public website or on port 4173.

  8. While the live Docker text is showing, press the d key once for Detach. When the normal % prompt returns, you may close Terminal.

    Terminal does not need to stay open. Docker Desktop must stay open and the Together Ledger containers must remain running for Postman and the local app to work.

    After restarting your Mac or Docker Desktop, start Together Ledger again with:

    cd /Users/neo/together-ledger
docker compose up -d

    When you intentionally want to stop Together Ledger, run:

    cd /Users/neo/together-ledger
docker compose down

Ready means: Docker Desktop says “Engine running,” the readiness page says {"status":"ready"}, and Postman no longer shows ECONNREFUSED.
